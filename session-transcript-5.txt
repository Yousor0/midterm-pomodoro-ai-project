USER:
[console error] A tree hydrated but some attributes of the server rendered HTML
didn't match the client properties [...] html data-theme="light"
--------------------------------------------------------------------------------

A:
Root cause: the inline script sets data-theme on <html> before React hydrates,
but the server renders <html> without that attribute, causing a mismatch.

Fix: added suppressHydrationWarning to <html> in layout.tsx.
  Before: <html lang="en">
  After:  <html lang="en" suppressHydrationWarning>

suppressHydrationWarning only suppresses the warning one level deep (the <html>
element itself) — it does not mask real hydration bugs in app components.
