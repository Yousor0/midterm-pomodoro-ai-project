ASSISTANT:
Reviewed all files and found four issues:

BUG 1 — useSettings.save not memoized
  File: app/hooks/useSettings.ts
  Problem: save() was a plain function, recreated every render, causing
           unnecessary re-renders downstream.
  Fix: Wrapped in useCallback([], []).

BUG 2 — Stale closure in Settings.tsx handleKey
  File: app/components/Settings.tsx
  Problem: handleKey was useCallback([draft]) but called handleSave() which
           referenced onSave and onClose from the closure. Since onSave was
           an inline arrow in PomodoroTimer, it changed every render but was
           not in the deps array, leaving a stale reference.
  Fix: Extracted handleSave into its own useCallback([draft, onSave, onClose]),
       updated handleKey deps to [handleSave, onClose].
       Memoized onSave and onClose at the call site in PomodoroTimer with
       useCallback (handleSettingsSave, handleSettingsClose).

BUG 3 — NumInput required clicking +/- for every increment
  File: app/components/Settings.tsx
  Problem: The value display was a non-editable <span>, so setting e.g. 45min
           work duration required 20 clicks.
  Fix: Replaced span with <input type="number">, styled to match terminal
       aesthetic, browser spin buttons hidden via Tailwind utility classes.
