BUG FIXED — UTC vs local date mismatch (all in useSessionStats.ts):

- todayStr() used new Date().toISOString() which returns UTC time. For anyone
  in a UTC+ timezone, after midnight UTC the date flips to "tomorrow" while
  it's still "today" locally.
- Fixed by introducing localDateStr() that uses getFullYear/getMonth/getDate
  (local time).
- Weekly filter changed from Date.now() millisecond math to string comparison
  (d.date >= sevenDaysAgo) — consistent with local dates.
- Streak's yesterday anchor changed to use prevDay(today) instead of
  Date.now() - 86_400_000.
- Streak loop now tracks `expected` as a string stepped with prevDay() instead
  of getTime() - 86_400_000 — the old approach could skip a day during DST
  transitions. prevDay() parses at noon local time to avoid DST edge cases.
